🌐 Hospedando um site do zero, 100% via linha de comando na AWS!

Concluí mais um laboratório prático de Cloud Computing, dessa vez publicando um site estático completo no Amazon S3 — tudo feito via AWS CLI, sem usar o console gráfico em nenhuma etapa.

Na prática, isso envolveu:

🔑 Conexão segura à instância EC2 via Session Manager (sem SSH)
🪣 Criação de um bucket S3 usando aws s3api create-bucket
👤 Criação de um usuário IAM com acesso total ao S3
🔓 Ajuste de permissões do bucket para acesso público de leitura
⬆️ Upload de todos os arquivos do site com aws s3 cp --recursive
🔁 Criação de um script em lote para automatizar futuras atualizações do site

O resultado final foi o site de uma cafeteria fictícia (Café ☕) no ar, hospedado inteiramente no S3 — um ótimo exercício de como a AWS CLI pode acelerar (e automatizar) todo o ciclo de publicação de um site estático.
